FairPayv0.4.1

AI-audited payroll on GenLayer StudioNet

Workers submit IPFS evidence, AI validators audit it against an agreed rubric, and pay is settled by quality tier with reserved-liability protection. This page is the entry point; the real tool is the interactive single-page app below.

Launch interactive app Frontend source Explorer

Interactive UI demo (48s, captions)

Real-time multi-gateway validation, the ipfs.io.evil.com lookalike rejection, the reserved-liability bars, and a live gen_call read of the deployed contract.

1. Gateway Validator

Type any evidence URL and watch the exact on-chain gate decide, with a step-by-step reason for every rejection. Same anchored regexes and 500-char cap as _is_content_addressed_url.

2. Reserved-Liability Calculator

Drag hours and rate, pick a tier, and see the reserve (hours x rate x 1.25, rounded up) always cover the max reachable payout so a live appeal window can never be defunded.

3. Live Contract State

Reads contract_balance(), get_job() and reserved_liability() straight from StudioNet over JSON-RPC, decoded in-browser with an SDK-verified genbase codec.
